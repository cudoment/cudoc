Northlight Weather API v1

Northlight serves current conditions and short-range forecasts for a network of weather stations. This handbook is one set of Markdown documents that cudoc publishes three ways: as the site you are reading, as a bound PDF with a cover and contents page, and as a Word file with real styles. Every figure below is drawn from the reference pages, so a correction there reaches this page too.

How this handbook is built

The site, the PDF and the Word file come from one cudoc-export build run and one set of design tokens. The configuration is a single file, showcase.config.mjs, beside the documents.

Endpoints at a glance

Each row is one section of the endpoint reference. The method and the path are read from the table at the top of that section, and the description is its first paragraph.

Endpoint Method Path What it returns
Current conditions GET /v1/weather/current Returns the latest observation from one station.
Hourly forecast GET /v1/forecast/hourly Returns up to 48 hourly forecast points for one station.
Station directory GET /v1/stations Lists the stations a key may read, with their location and status.

Where to start

  1. Read Getting started for a key and a first request.
  2. Keep Rate limits open while you design a polling schedule.
  3. Check the release notes before upgrading a client.
